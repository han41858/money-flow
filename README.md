# Money Flow

개인 및 가구의 월간 자금 흐름을 다이어그램으로 작성하고 관리하는 웹 애플리케이션입니다.

수입이 어느 계좌로 들어와 어떤 계좌·카드로 이동하고, 최종적으로 어떤 명목으로 지출되는지 한 화면에 표현합니다.
구글 슬라이드로 그리던 자금 흐름도를 대체하는 것이 첫 번째 목표입니다.

## 현재 상태

Phase 1에서는 두 사람의 급여가 계좌·카드를 거쳐 생활비와 저축으로 이어지는 예제를 제공합니다. 캔버스에서 노드나 연결선을 선택하면 소유자와 월 금액을 확인할 수 있습니다. 빈 공간을 드래그해 이동하고 휠이나 화면 하단 버튼으로 확대·축소합니다.

## 개발 환경

Node.js 24와 package.json에 지정한 pnpm 버전을 사용합니다.

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`로 검사합니다. 빌드 후 `pnpm exec playwright install chromium`과 `pnpm test:e2e`로 브라우저 테스트를 실행합니다.

Vercel Git 연동이 기능 브랜치와 `dev`에 프리뷰를 생성하고, `main` 병합 시 프로덕션을 배포합니다. 배포 상태는 GitHub 체크와 Vercel에서 확인합니다.

## 주요 기능 (계획)

- 수입·계좌·카드·지출 노드를 자유롭게 배치하는 비주얼 편집기
- 금액 규모를 연결선 두께로 표현, 고정 금액과 최소·최대 범위 금액 지원
- 금융사 브랜드 컬러 적용
- 사용자별 자금 영역을 구분하는 그룹
- 브라우저 로컬 저장, JSON 가져오기·내보내기
- URL 공유, SVG·PNG 내보내기

로그인과 백엔드 없이 브라우저에서 독립적으로 동작합니다.

## 브랜치

| 브랜치 | 역할                                                 |
| ------ | ---------------------------------------------------- |
| `dev`  | 기본 브랜치. 기능 브랜치의 분기점이자 PR 기준 브랜치 |
