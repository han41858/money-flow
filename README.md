# Money Flow

개인 및 가구의 월간 자금 흐름을 다이어그램으로 작성하고 관리하는 웹 애플리케이션입니다.

수입이 어느 계좌로 들어와 어떤 계좌·카드로 이동하고, 최종적으로 어떤 명목으로 지출되는지 한 화면에 표현합니다.
구글 슬라이드로 그리던 자금 흐름도를 대체하는 것이 첫 번째 목표입니다.

## 시작하기

저장된 흐름이 없으면 빈 캔버스에서 시작합니다. 다시 열거나 새로고침하면 목록에서 저장된 흐름을 골라 이어서 편집하거나 **새 흐름 시작**을 선택할 수 있습니다. 변경 사항은 이 브라우저의 IndexedDB에 자동 저장됩니다.

1. 왼쪽 도구에서 수입·계좌·카드·지출을 추가하고 드래그해 배치합니다.
2. 출발 노드의 오른쪽 점을 도착 노드의 왼쪽 점으로 끌어 연결합니다. 키보드로는 출발 노드를 선택한 뒤 속성 패널의 **연결할 노드**에서 대상을 고르고 **연결 추가**를 누릅니다.
3. 노드나 연결선을 선택해 속성 패널에서 이름·금융사·분류 또는 월 금액과 메모를 입력합니다. Enter 또는 포커스 이동으로 입력을 확정합니다. 범위 금액은 두 값을 입력한 뒤 확정합니다.
4. Ctrl(맥은 ⌘)을 누른 채 여러 객체를 선택해 함께 이동하거나 Delete·Backspace로 삭제합니다. Ctrl/⌘+Z로 취소하고 Ctrl/⌘+Shift+Z로 다시 실행합니다.

Tab으로 도구와 캔버스 객체 사이를 이동합니다. 노드나 연결선에서 Enter 또는 Space로 선택하고, 선택한 노드는 방향키로 옮길 수 있습니다. 작은 화면에서는 제목 옆 목록 버튼으로 노드를 찾습니다. 패널은 닫기 버튼이나 Esc로 닫습니다.

새 계좌와 카드의 금융사는 속성 패널에서 선택합니다. 미지정 상태로도 편집할 수 있습니다.

월 수입·소비·저축은 연결선의 최소·최대 금액을 합산합니다. 대출 상환 노드를 추가하면 해당 금액도 별도 지표로 확인할 수 있습니다.

## 그룹으로 영역 구분하기

**그룹 추가**를 누르면 캔버스에 영역을 만듭니다. 노드를 먼저 선택하면 선택한 노드를 둘러싸는 크기로 생성됩니다. 그룹 제목을 끌면 소속 노드가 함께 이동합니다. 오른쪽 아래 핸들이나 속성 패널에서 크기를 조절하고, 그룹 이름과 배경색을 바꿀 수 있습니다.

노드를 옮기면 중심점이 들어간 그룹에 소속됩니다. 영역이 겹치면 나중에 만든 그룹이 우선합니다. 그룹만 삭제하면 노드와 연결선은 원래 위치에 남습니다.

## 흐름 관리와 백업

**내 흐름**에서 저장된 흐름을 열고 현재 흐름의 이름을 바꾸거나 복제·삭제할 수 있습니다. **JSON 내보내기**로 백업하고 **JSON 가져오기**로 별도의 흐름을 만듭니다. 파일에는 노드, 연결선, 그룹, 금융사와 캔버스 위치가 포함됩니다.

다른 탭에서 같은 흐름을 수정하면 자동 저장이 일시 중지됩니다. 최신 내용을 불러오거나 현재 탭 내용으로 계속할 수 있습니다. 저장에 실패하면 변경 내용을 JSON으로 백업하거나 저장을 다시 시도하세요.

## 공유와 이미지 저장

**공유 및 내보내기**에서 포함될 이름과 금액을 확인하고 읽기 전용 링크를 만듭니다. 링크에 담긴 내용은 링크를 가진 누구나 읽고 복사할 수 있습니다. 링크를 짧게 만들기 위해 좌표는 1px 단위로 맞춰 담습니다. 8,000자를 넘으면 JSON 파일로 공유하세요. 수신자가 **내 다이어그램으로 복사**를 선택하면 편집 가능한 새 로컬 흐름이 생깁니다.

**SVG 저장**은 전체 흐름을 벡터로, **PNG 저장**은 같은 그림을 흰 배경과 40px 여백을 포함한 2배 해상도로 내려받습니다.

## 개발 환경

Node.js 24와 package.json에 지정한 pnpm 버전을 사용합니다.

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`로 검사합니다. 빌드 후 `pnpm exec playwright install chromium`과 `pnpm test:e2e`로 브라우저 테스트를 실행합니다.

Vercel Git 연동이 기능 브랜치와 `dev`에 프리뷰를 생성하고, `main` 병합 시 프로덕션을 배포합니다. PR·커밋 댓글은 꺼 두며 배포 상태는 GitHub 체크와 Vercel에서 확인합니다.
